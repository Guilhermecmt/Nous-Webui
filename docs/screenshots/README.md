# Screenshots

Prints reais da versão 2.10, usados nos dois READMEs. Foram feitos numa instância separada do Nous, com uma pasta de dados de demonstração e uma usuária fictícia ("Ana"), para não mostrar dados de ninguém. Os prints do Nous Code mostram o próprio repositório e um projeto de exemplo.

| Arquivo | O que mostra |
|---|---|
| `inicio-escuro.png` | Tela inicial no tema escuro, com o painel "Seu Nous" (topo dos READMEs) |
| `inicio-claro.png` | Tela inicial no tema claro |
| `conversa.png` | Uma resposta com "Mais curto", "Mais simples" e "Documento" |
| `documentos.png` | Documentos revisando as sugestões da IA |
| `loja.png` | Loja de modelos com recomendação para a placa de vídeo |
| `nous-code.png` | Nous Code: editor, terminal e um plano proposto pelo agente |
| `nous-code-diff.png` | Nous Code: o agente pede para aplicar uma correção, com o diff |

As imagens são capturadas a 1440×900 com escala de 1,5 (as do Nous Code, a 1600×960 com escala de 1,35). Os outros arquivos desta pasta são artes de divulgação: `github-social-preview.png` é a imagem de prévia do repositório.
